# ValidaBR 7.0 — anúncios responsivos

Publique `index.html`, `style.css` e `script.js` na raiz do repositório GitHub Pages.

## Anúncios desta versão (substituem todos os anteriores)

- Desktop (largura >= 768px), sob a apresentação: `728×90` (`y79304a4213`).
- Mobile (largura < 768px), no mesmo local: `320×50` (`hfa79a11bf6`).
- Após a calculadora: `300×250` (`gccaeb53ce7`).
- Depois de “Como funciona?”, antes do rodapé: `300×250` (`i493141e048`).

Os banners têm contêineres reservados e não aparecem na impressão. A visibilidade é controlada por CSS: scripts de terceiros ainda podem executar mesmo em espaços ocultos; para impedir completamente requests de anúncios ocultos, seria necessária integração específica com o provedor.

## Calculadora
- Data de fabricação automaticamente preenchida com a data atual de Brasília; permite selecionar data manual.
- Prazos rápidos: 30, 60, 90, 180, 365 dias.
- Prazo personalizado de 1 a 36.500 dias.
- Resultado, conferência do produto, cópia e etiqueta para impressão.
- Referência: 07/07/2026 + 60 dias = 05/09/2026.

## Atenção
Scripts publicitários externos não foram auditados e precisam ser testados no site publicado, inclusive para pop-ups e redirecionamentos. O cálculo não determina prazos sanitários.
