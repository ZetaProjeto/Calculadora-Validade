# ValidaBR v3 — Calculadora de validade

Site estático para GitHub Pages. Publique `index.html`, `style.css` e `script.js` na raiz do repositório.

## Funcionalidades
- Data de Fabricação, usando horário de Brasília como sugestão inicial.
- Prazo **somente em dias corridos**: 30, 60, 90, 180, 365 ou personalizado.
- Nome do produto começa vazio; a seção **Conferência** atualiza conforme o nome preenchido.
- Copiar o resultado e imprimir etiqueta. Para ocultar o cabeçalho/rodapé que o navegador insere (data, título, URL), desative **Cabeçalhos e rodapés** nas opções avançadas de impressão. O CSS define margem de página zero, mas não pode controlar todas as preferências dos navegadores.

## Teste
07/07/2026 + 60 dias = 05/09/2026.

## Segurança
Esta ferramenta não define o prazo sanitário de um alimento. Utilize o prazo estabelecido pelo fabricante e não substitua a validade do rótulo.
